# VisionWithShades – Add Sunglasses for a Cool New Look

## Overview

VisionWithShades is a creative image processing project that automatically adds sunglasses to photos. It is designed to detect faces in passport-size or portrait images and place a stylish sunglasses overlay for a fun visual transformation.

This project is a great way to explore the basics of computer vision while building something entertaining and interactive.

## Features

* Detects faces in an image automatically
* Adds sunglasses overlay aligned to the face
* Works well with passport-size and portrait photos
* Easy to customize with different sunglass styles
* Beginner-friendly computer vision project

## Technologies Used

* Python
* OpenCV for face detection and image processing
* NumPy for image and array operations

## How to Use

1. Clone or download this repository.
2. Add your passport-size photo to the `images` folder.
3. Run the script.
4. View your transformed image with sunglasses applied.

## Applications

* Learn basic image processing concepts
* Practice face detection techniques
* Create fun and stylish photo edits
* Explore beginner computer vision projects
